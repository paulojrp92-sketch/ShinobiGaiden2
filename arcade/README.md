# Shinobi Gaiden Arcade

This is the independent arcade game project. Run commands from this directory.

```sh
cd arcade
npm install
npm run dev
```

`npm run build` runs strict TypeScript checks and creates `dist/`.
`npm test` runs deterministic engine tests.

This branch reconstructs the unavailable workspace implementation from the agreed game architecture and character specifications. It is not a recovered copy of the inaccessible source. The portal project at the repository root is separate.

Current checkpoint: Phaser + TypeScript + Vite foundation and 60 Hz simulation clock.
